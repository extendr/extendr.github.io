Build blazingly fast R packages with Rust

extendr provides developer-first tooling and support for publishing to CRAN. 

# setup R package
usethis::create_package("helloextendr")

# add extendr scaffolding
rextendr::use_extendr()

# build and document package
devtools::document()

# load package
devtools::load_all()

# call rust function
hello("world")
[1] "Hello world!"
